# Platform Adaptation

## General rule

Place the full skill as high as possible in the instruction hierarchy.

## ChatGPT / custom assistants
Use the full skill as a system or developer instruction.

## Claude
Place the skill in the system prompt or project instruction block.

## Gemini
Use the skill as a persistent instruction set and keep task-specific instructions separate.

## DeepSeek and similar platforms
Use the full skill first, then provide the project material and output request.

## Workflow tools
Map the skill into a reusable prompt node and keep source material in downstream task inputs.
