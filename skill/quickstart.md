# Quick Start

## Minimal usage

1. Load `skill.md` as a system prompt, developer prompt, or equivalent high-priority instruction.
2. Provide the source material.
3. State the target platform, audience, and desired outcome.
4. Ask for a full draft.
5. Review against the quality checklist.

## Recommended input

Provide:

- what the project or topic is
- what problem it solves
- technical stack or architecture
- target audience
- target platform
- desired tone
- desired action or conversion goal

## Best practice

The more concrete the source material, the better the result.
Do not ask this skill to invent depth where the project itself has none.
